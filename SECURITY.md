# Security and privacy

The browser processes the input locally and does not transmit submitted text to a scan service. The stylesheet uses Google Fonts, which can make separate requests to Google for font files; use system fonts or self-host only fonts you are licensed to distribute if complete third-party request isolation is required. The scanner does not visit input URLs.

Do not enter secrets, passwords, access codes, financial details, or identifying information. The site is a heuristic educational tool, not malware protection or phishing reputation verification. A low score is not evidence of safety. No personal data is intentionally stored by the scanner.

Before commercial launch: remove external font dependencies if a strict privacy claim is required; implement CSP, security headers, dependency review, threat modeling, accessibility testing, disclosure policy and verified support contacts.
