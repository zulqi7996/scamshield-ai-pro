# Product requirements

## Intended audience
Internet users, parents, students, freelancers, and small business teams.

## Current MVP
Message heuristics, URL text heuristics, visible explanations, sample, reset, copy report, text report download, responsive landing page and honest proposed pricing.

## Exclusions
No actual machine learning model, malware scans, reputation API, real-time domain reputation, OCR, browser extension, user accounts, paid subscriptions, team dashboard, or alerts. Do not market these as shipped.

## Trust requirements
Always say heuristics are not safety guarantees. Never recommend visiting suspicious sites to test them. Never collect OTP, passwords, card details, or secrets. Results must never be called definitive.
